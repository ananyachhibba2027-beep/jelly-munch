# Jelly Munch 🍓

A quick, juicy snake game for your breaks. Steer a jelly snake, munch fruit, dodge walls and your own tail.

**Play:** https://jelly-munch-site.vercel.app

## Features
- 3 themed worlds (Candy Garden, Ice Pop Lake, Choco Volcano) plus endless levels
- Lives, stars, combos, golden fruit and bonus rounds
- Power-ups: extra life, ghost mode, slow-mo, fruit magnet, double munch, snip, bubble shield
- Unlockable jelly skins
- Global leaderboard and optional sign-in to save progress across devices
- Sound effects and a Chill mode

## Tech
A single `index.html` file: HTML, CSS and JavaScript (canvas), with Supabase for the leaderboard and accounts. Hosted on Vercel.

## Run locally
Download `index.html` and open it in your browser.
